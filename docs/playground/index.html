API for AI Browsers

            
This playground exposes a JavaScript API for programmatic access:

            
// Verify a trace against a card
const result = await window.AAP.verifyTrace(traceJson, cardJson);

// Check coherence between two cards
const result = await window.AAP.checkCoherence(myCardJson, theirCardJson);

// Detect drift in a trace sequence
const result = await window.AAP.detectDrift(cardJson, tracesJson, {
    similarityThreshold: 0.3,
    sustainedThreshold: 3
});

// URL Parameters (for AI browser navigation):
// ?mode=verify|coherence|drift
// ?card=base64_encoded_json
// ?trace=base64_encoded_json
// ?auto=true (auto-run on load)
